# 🎭 Digital Bridge — Интерактивная рассадка гостей

Веб-приложение для управления рассадкой гостей в зрительном зале на **500 мест** с системой **персональных QR-кодов** и **панелью администратора**.

---

## 📋 Возможности

### Главная страница — Схема зала
- Интерактивная SVG-схема зала с 500 кликабельными местами
- 3 сектора: Левый (160 мест), Центральный (180 мест), Правый (160 мест)
- 3 входа (A, Б, В) и экран отмечены на схеме
- Цветовая кодировка: 🟢 свободно, 🔵 занято, 🟡 выбрано
- Правая панель с информацией о месте: ФИО гостя, ряд/место, QR-код

### Панель администратора
- Защищённый вход по логину и паролю
- Загрузка списка гостей из Excel (.xlsx)
- Автоматическое распределение гостей по местам
- Ручное перемещение (swap) гостей между местами
- Снятие гостя с места / очистка всех назначений
- Таблица гостей с поиском по ФИО

### Персональные QR-коды
- Каждому гостю присваивается **постоянный уникальный токен**
- QR-код привязан к гостю, а **не к месту** — при пересадке QR не меняется
- При сканировании QR система показывает **актуальное** место гостя

### Мобильная навигация (по QR)
- Пошаговая инструкция: через какой вход войти, куда повернуть
- Мини-схема зала с анимированным маршрутом от входа к месту
- Адаптивный дизайн для смартфонов

## 🚀 Быстрый старт

### Требования
- **Python 3.10+**

### Установка и запуск

```bash
# 1. Перейти в папку проекта
cd "digital bridge"

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить сервер
python main.py
```

Сервер запустится на **http://localhost:8000**

> При первом запуске автоматически создаётся база данных `hall.db` с 500 местами.

### Доступ с других устройств в сети

Сервер слушает `0.0.0.0:8000`, поэтому доступен по IP вашего компьютера. Чтобы узнать IP:

```bash
# Windows
ipconfig

# Linux/Mac
hostname -I
```

Откройте в брандмауэре порт 8000 (Windows — от имени администратора):

```powershell
netsh advfirewall firewall add rule name="Digital Bridge" dir=in action=allow protocol=TCP localport=8000
```

Затем все устройства в сети могут открыть: `http://<ваш-IP>:8000`

## 📖 Как пользоваться

### 1. Подготовка списка гостей

Создайте Excel-файл (.xlsx) со списком ФИО — **по одному имени в строке**, в первом столбце:

| A |
|---|
| ФИО |
| Иванов Иван Иванович |
| Петрова Анна Сергеевна |
| Козлов Дмитрий Олегович |
| ... |

Первая строка с заголовком (ФИО, Имя, Name и т.п.) будет пропущена автоматически.

### 2. Загрузка и распределение

1. Откройте **http://localhost:8000/admin/login**
2. Введите логин и пароль
3. Перетащите Excel-файл в зону загрузки или нажмите для выбора
4. Нажмите **«Загрузить и распределить»**
5. Гости автоматически распределятся по местам (сначала Центр, затем Лево, затем Право)

### 3. Ручная корректировка

- **Переместить гостя:** выберите гостя в выпадающем списке «Откуда» и место в списке «Куда», нажмите «Переместить»
- **Снять с места:** в таблице гостей нажмите «Снять с места» — гость сохраняется в системе, его QR не меняется
- **Очистить всё:** снимает всех гостей с мест (записи гостей и их QR-коды сохраняются)

### 4. Раздача QR-кодов

- Кликните на любое занятое место на схеме → в правой панели отобразится **персональный QR-код** гостя
- Распечатайте или отправьте QR гостю
- Гость сканирует QR камерой телефона → открывается страница с навигацией к его месту

### 5. Повторная загрузка

При повторной загрузке Excel:
- Гости с теми же ФИО **сохраняют свои QR-коды** (токены не перегенерируются)
- Новые имена получают новые токены
- Все места перераспределяются заново

## 🏗 Архитектура зала

```
┌──────────────────────────────────────────────────┐
│                    🖥 ЭКРАН                       │
├──────────────────────────────────────────────────┤
│                                                  │
│  ┌──────────┐  ┌──────────────┐  ┌──────────┐   │
│  │  ЛЕВЫЙ   │  │ ЦЕНТРАЛЬНЫЙ  │  │  ПРАВЫЙ  │   │
│  │  сектор  │  │    сектор    │  │  сектор  │   │
│  │          │  │              │  │          │   │
│  │ 8 мест × │  │  9 мест ×   │  │ 8 мест × │   │
│  │ 20 рядов │  │  20 рядов   │  │ 20 рядов │   │
│  │ = 160    │  │  = 180      │  │ = 160    │   │
│  └──────────┘  └──────────────┘  └──────────┘   │
│                                                  │
│  [Вход A]       [Вход Б]         [Вход В]        │
└──────────────────────────────────────────────────┘

Итого: 160 + 180 + 160 = 500 мест
```

Навигация по входам:
- **Левый сектор** → Вход A
- **Центральный сектор** → Вход Б
- **Правый сектор** → Вход В

## 💡 Ключевые особенности реализации

### Постоянные QR-коды
QR-код содержит ссылку вида `/guest/{uuid-токен}`. Токен генерируется **один раз** при импорте гостя и **никогда не меняется** — ни при пересадке, ни при повторной загрузке Excel. При сканировании система находит гостя по токену и показывает его **текущее** место.

### Модель данных
```
Guest (id, name, token)  ←──  Seat (id, sector, row, number, guest_id FK)
```
Перемещение гостя = изменение `guest_id` на записи `Seat`. Запись `Guest` не затрагивается.

### Безопасность
- Админ-панель защищена подписанными cookie-сессиями
- Все админские API проверяют авторизацию
- Пароль можно задать через переменные окружения
