# 🎭 AI&DIGITAL BRIDGE — Интерактивная рассадка гостей

Веб-приложение для управления рассадкой гостей в зрительном зале на **500 мест** с умным поиском мест, **единой системой QR-доступа** и скрытой **панелью администратора**. Проект оформлен в современной технологичной стилистике (animated orbs, glassmorphism).

---

## 📋 Возможности

### Главная страница — Схема зала и Дашборд
- Интерактивная SVG-схема зала с 500 кликабельными местами.
- **Умный поиск:** гости вводят своё имя, выбирают себя из выпадающего списка — на схеме подсвечивается их место и рисуется анимированный маршрут от входа.
- 3 сектора: Левый (160 мест), Центральный (180 мест), Правый (160 мест).
- 3 входа (A, Б, В) и экран отмечены на схеме.
- Цветовая кодировка: 🟢 свободно, 🔵 занято, 🟡 выбрано, 🔴 ваше место.
- Боковая панель с информацией о месте: ФИО гостя, сектор/ряд/место и **единый QR-код** для входа на дашборд.

### Единый QR-вход
- Вместо генерации сотен персональных QR-кодов используется **один общий QR-код**.
- При сканировании QR-кода любой гость попадает на главную страницу (дашборд).
- На главной странице гость находит себя через поиск и видит своё актуальное место. Это гарантирует, что даже после пересадок гость найдёт правильное кресло.

### Панель администратора (Скрытая)
- Скрыта от обычных пользователей (ссылки в интерфейсе нет, доступ только по прямому URL `/admin/login`).
- Загрузка списка гостей из Excel (.xlsx) с автоматическим распределением.
- Ручное перемещение (swap) гостей между местами без нарушения данных.
- Снятие гостя с места / очистка всех назначений.
- Таблица гостей с поиском по ФИО.

### Современный дизайн
- Тёмная технологичная цветовая гамма (`#060918`).
- Анимированный фон: плавно движущиеся градиентные пятна (orbs) синего, фиолетового и бирюзового цветов.
- Эффект матового стекла (glassmorphism) для интерфейсных панелей.
- Полная адаптивность под мобильные устройства (с оптимизацией производительности фона).

## 🚀 Быстрый старт

### Требования
- **Python 3.10+**

### Установка и запуск

```bash
# 1. Перейти в папку проекта
cd "digital bridge"

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить сервер
python main.py
```

Сервер запустится на **http://localhost:8000**

> При первом запуске автоматически создаётся база данных `hall.db` с 500 местами.

### Доступ с других устройств в сети

Сервер слушает `0.0.0.0:8000`, поэтому доступен по IP вашего компьютера. Чтобы узнать IP:

```bash
# Windows
ipconfig

# Linux/Mac
hostname -I
```

Откройте в брандмауэре порт 8000 (Windows — от имени администратора):

```powershell
netsh advfirewall firewall add rule name="Digital Bridge" dir=in action=allow protocol=TCP localport=8000
```

Затем все устройства в сети могут открыть: `http://<ваш-IP>:8000`

## 📖 Как пользоваться

### 1. Подготовка списка гостей

Создайте Excel-файл (.xlsx) со списком ФИО — **по одному имени в строке**, в первом столбце:

| A |
|---|
| ФИО |
| Иванов Иван Иванович |
| Петрова Анна Сергеевна |
| Козлов Дмитрий Олегович |
| ... |

Первая строка с заголовком будет пропущена автоматически.

### 2. Загрузка и распределение (в Админке)

1. Откройте напрямую URL **http://localhost:8000/admin/login**
2. Введите логин и пароль.
3. Перетащите Excel-файл в зону загрузки.
4. Гости автоматически распределятся по местам (сначала Центр, затем Лево, затем Право).

### 3. Ручная корректировка

- **Переместить гостя:** выберите гостя в выпадающем списке «Откуда» и место в списке «Куда», нажмите «Переместить».
- **Снять с места:** в таблице гостей нажмите «Снять с места».
- При повторной загрузке Excel система интеллектуально обновит список (добавит новых, сохранит токены).

### 4. Взаимодействие с гостями

- Распечатайте или выведите на экран **Единый QR-код** (доступен в правой панели при клике на любое место).
- Гость сканирует QR камерой телефона → попадает на дашборд.
- Гость вводит своё имя в поиске → нажимает на подсказку → система строит маршрут от входа до его кресла.

## 🔌 API-эндпоинты

### Публичные

| Метод | Маршрут | Описание |
|-------|---------|----------|
| GET | `/` | Главная — схема зала (дашборд) |
| GET | `/api/seats` | JSON массив всех 500 мест |
| GET | `/api/seat/{id}` | Детальная информация о месте |
| GET | `/api/hall-config` | Конфигурация зала (сектора, входы) |
| GET | `/api/dashboard-qr`| Возвращает base64 единого QR-кода, ведущего на дашборд |
| GET | `/guest/{token}` | Навигация по токену (оставлено для обратной совместимости) |

### Администратор (требуется авторизация)

| Метод | Маршрут | Описание |
|-------|---------|----------|
| GET | `/admin` | Панель управления |
| POST | `/admin/login` | Авторизация |
| POST | `/admin/upload` | Загрузка Excel + автораспределение |
| POST | `/admin/assign` | Перемещение (swap) гостей |
| POST | `/admin/assign-single` | Снять гостя с места |
| GET | `/admin/guests` | Список всех гостей с местами |

## 💡 Ключевые особенности реализации

### Гибкий UI с правильным z-index
Все всплывающие окна поиска и подсказок корректно позиционируются поверх интерактивной SVG-карты благодаря продуманной иерархии `z-index` и отказу от `overflow: hidden` в критичных контейнерах.

### Оптимизированный поиск
Поиск происходит мгновенно на стороне клиента (массив загруженных мест). При клике на имя функция `highlightGuestSeat` не просто выбирает место, но и динамически рисует SVG-линию маршрута (`polyline`) от соответствующего входа.

### Развязка "Гость" - "Место"
Данные разделены на таблицы `Guest` (люди) и `Seat` (кресла). При перемещении (swap) меняется только `guest_id` на кресле. Сами записи гостей никогда не удаляются, что гарантирует целостность системы.
